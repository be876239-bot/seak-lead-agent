# 高评论量帖子采集修复报告（2026-10-18）

> 预算更新（2026-10-20）：本文中的15分钟/1000轮是当时的旧上限，已由D028取代。当前采集预算为每100条5分钟，最高100分钟/4000轮；单篇整体主动保护最高130分钟。历史验收结论与2000条安全上限不变。

## 结论

已完成代码修复和自动化验收。单帖评论安全上限从500提高到2000；当采集达到安全上限、动态预算耗尽，或页面显示评论数高于实际采集数时，插件会保留已采集评论、跳过AI分析，并将该帖子明确标记为部分采集。多帖任务会继续处理下一篇，整项任务最终标记为 partial，而不是把未采全的数据误报为完整成功。

## 修改内容

1. 统一限制：采集器、消息响应Schema、任务检查点、恢复读取与UI文案统一使用2000条上限；继续任务时不会把已保存评论截回500条。
2. 不完整门禁：当前笔记分析和多帖寻找客户共用同一判定。达到2000条、页面显示数高于采集数，或采集时间/轮数预算耗尽时，不提交AI分析。
3. 部分状态：将此类帖子写入 partial 检查点，保存原因与采集数量，并在侧边栏显示部分采集数量；多帖任务自动推进后续帖子。
4. 自动测试：覆盖2000条上限、已保存评论恢复、页面显示1500条但实际采集不足、部分任务状态及检查点。

# D022 — 统一大白话错误提示

日期：2026-10-18

## 目标

用户遇到报错时，不应只看到技术错误码或难以理解的异常文字。提示需要说明发生了什么、对当前任务有什么影响、已保存的数据是否保留、下一步应做什么；详细技术信息默认折叠，供后续排查使用。

## 实现

- 新增 `src/ui/error-copy.ts`：按错误码/错误文字映射到用户可理解的说明，覆盖权限、链接、页面变化、平台验证、页面不可达、采集解析、任务冲突、AI 鉴权/限流/超时/格式错误、取消、本地存储和未知错误。
- 新增 `src/ui/ErrorNotice.tsx`：统一显示“发生了什么 / 当前影响 / 建议操作”，提供可展开的技术详情。
- 技术详情最多显示 600 字，并对常见 API Key、Bearer Token、Cookie 等内容进行脱敏。
- 接入寻找客户、产品识别、当前笔记分析三个主要侧边栏页面；寻找客户的暂停原因也通过同一说明机制展示。
- 当前笔记分析的状态行不再直接向普通用户显示原始错误码。

## 手动验收

1. 在 Edge 打开 `edge://extensions` 并重新加载 SeekLead Agent。
2. 打开插件，在“寻找客户”或“产品识别/当前笔记分析”触发一种可安全复现的错误。
3. 确认主提示包含发生原因、当前影响、已保存数据状态和下一步操作。
4. 确认技术详情默认折叠；展开后能看到错误代码/原始说明，且不会显示测试密钥或常见 Token。
5. 确认错误提示不覆盖正常操作按钮，且历史线索仍在。

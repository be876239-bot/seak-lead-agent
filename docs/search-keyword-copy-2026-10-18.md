# D025 — 搜索关键词复制与操作指引（2026-10-18）

## 目标

解决用户可能忘记把产品画像生成的搜索建议输入小红书搜索框的问题，降低第一次使用时的操作歧义。

## 实现

- 新增 `src/ui/clipboard.ts`：优先使用 Clipboard API；在扩展上下文拒绝该 API 时回退到临时 textarea 复制；复制失败时抛出明确中文提示。不新增 `clipboardWrite` 权限。
- “产品”页的产品画像将每条建议搜索词单独列出，并提供“复制关键词”按钮；复制成功会提示用户切回小红书搜索框粘贴并搜索。
- “寻找客户”页增加醒目的“第 1 步：复制并搜索关键词”区域，当前关键词/分析方向旁提供“复制当前关键词”按钮。
- 明确告诉用户：插件不会自动输入或提交小红书搜索；用户需切回已登录的小红书页面，粘贴到搜索框并执行搜索。
- 新增启动前确认框。用户必须确认当前小红书页面已显示搜索结果，才能启动新任务；更换产品、关键词或再次复制后会清除确认状态，避免沿用过期确认。
- 未修改评论采集、自动切帖、AI 分析、任务检查点、历史线索数据或持久化 schema。

## 手动验收步骤

1. 在 Edge 打开 `edge://extensions`，重新加载觅客 Agent。
2. 打开“产品”，展开某个产品画像，逐条点击“复制关键词”，在记事本中粘贴验证内容完全一致。
3. 打开“寻找客户”，选择一个关键词并点击“复制当前关键词”；切回小红书搜索框粘贴、执行搜索。
4. 未勾选“我已在小红书搜索框中搜索该关键词，并确认当前页面已显示搜索结果”时，开始按钮应不可用。
5. 勾选后开始按钮可用；切换产品或关键词、再次点击复制后，确认应自动取消，必须重新确认。
6. 若复制失败，界面应给出明确提示；确认该流程不改变历史线索和已保存评论。

# 评论数量与采集完整性提示

日期：2026-10-17

## 实现

- 从经过历史脱敏真实页面 fixture 证实的 `#noteContainer .comments-el .total` 读取显示的评论总数。
- 支持整数与“万”单位；无法解析时返回 unknown，不猜数字。
- 通过内容脚本快照与采集进度消息传递显示数，侧边栏显示页面显示数、实际发现数及完整性提示。
- 当显示总数明确大于当前已采集记录数时，跳过本帖 AI 分析并保留本地采集结果，避免对明显不完整的数据消耗模型额度；串行寻找客户任务记录 `ANALYSIS_SKIPPED_INCOMPLETE` 并继续处理后续帖子。

## 重要限制

页面显示数的统计口径可能与插件可访问的 DOM 不一致，尤其是折叠回复、隐藏评论、不可访问的内容及平台统计方式。因此数量达到或超过显示数仅是数量核对信号，不是“已全部读取”的证明。显示数不可读时状态为 unknown。当前 gate 是保守启发式：当采集数小于显示数时跳过 AI，不自动无限滚动，也不绕过平台限制。

已采集数据仍保存在本地。用户可检查页面、重新采集；AI Key 与账号凭据不进入日志。

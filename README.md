# 觅客Agent（SeekLead Agent）

觅客Agent 是一个本地浏览器插件，帮你从小红书笔记的评论区里找客户。

贴上你的产品链接，插件读取网页并自动生成带证据的产品画像；你在浏览器里手动打开一篇相关小红书笔记，点击“开始采集评论（完成后分析）”。插件小步滚动当前笔记，通过网页自身懒加载持续提取、脱敏、去重并逐轮保存评论（每轮采集最多500条），再用你自己的国内 AI Key 分析，输出四组线索。每条线索附评论原文、判断理由和证据，你点进原帖自己回复。

插件只做发现与分析：用户启动后仅在当前笔记内滚动加载，不自动搜索、不点击互动按钮、不替你发私信，也不碰账号密码或 Cookie。所有业务数据保存在本机 IndexedDB，可随时导出或删除。

> 支持 Chrome / Edge；本轮已实现滚动增量采集，真实小红书兼容性尚未验收。平台限制、折叠回复和停止条件可能使结果不完整，不承诺全量。

## 环境要求

- Node v24.13.0（历史验证）或 v26.7.0（本轮验证）、pnpm 10.33.0
- Chrome 或 Edge 桌面版（Firefox 行为未测试，不支持 Safari 语法）
- 一个阿里云百炼 API Key（OpenAI 兼容端点，默认模型 qwen3.8-flash）

## 安装与构建

```bash
pnpm install          # 安装依赖（postinstall 自动执行 wxt prepare）
pnpm build            # 生产构建，产物在 .output/chrome-mv3/
pnpm build:edge       # Edge 构建，产物在 .output/edge-mv3/
pnpm zip              # 打包 zip（另有 zip:edge）
pnpm typecheck && pnpm lint && pnpm test   # 静态检查与全量自动化测试
```

本轮使用 Node v26.7.0 / pnpm 10.33.0。若机器默认 pnpm 为 11，使用 `npx --yes pnpm@10.33.0 install --frozen-lockfile` 安装，并用同一前缀执行上述脚本；pnpm 11 会忽略当前 package.json 中的 pnpm.overrides，不能直接视为等价安装。

## 加载到浏览器（本地开发方式）

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 右上角开启**开发者模式**。
3. 点**加载解压缩的扩展**，选择 `.output/chrome-mv3/`（Edge 选 `.output/edge-mv3/`）。
4. 点击工具栏中的觅客Agent 图标即打开侧边栏（首次需允许侧边栏）。

## 使用流程

1. **配置 Key（设置页）**：粘贴百炼 API Key，可选“在此浏览器记住”（存 `storage.local`；不记住则仅当前会话 `storage.session`）。需要时点“授权模型域名”“连接测试”。Key 绝不进入同步存储、数据库、导出文件或日志。
2. **识别产品（产品页）**：粘贴产品官网链接 → 自动读取网页（静态优先，必要时临时标签渲染兜底，同域最多补读 2 页）→ 生成带证据的画像。未知信息保持“未知”，不要求填问卷；可取消、可删除、可重新生成（画像版本递增）。
3. **分析当前笔记（当前笔记页）**：手动打开笔记，点击“开始采集评论（完成后分析）”，无需手动滚动助载。进度显示已发现、本轮新增、是否加载中及停止原因；每次新增即落库，旧评论移出 DOM 也保留。连续4轮（每轮约2.5秒）未新增、500条上限、3分钟/200轮上限、取消或错误时停止；未新增不等于全部采集。已采集结果走原有模型批次和缓存；取消后不会继续写入，已保存评论保留。若画像、模型或上下文已变，旧分析批次重试需重新读取笔记。
4. **跟进线索（线索页）**：按分组/处理状态/关键词过滤，标记已处理，人工纠正分组（写纠正记录，不改也不覆盖模型原判），导出 JSON/CSV。
5. **数据生命周期（设置页）**：保留期 7/30/90 天（默认 30），启动与每日首次使用自动清理，也可“立即清理”（需先取消活跃任务）；“清除 Key”和“清除全部业务数据”是两个独立操作。

## 数据存储位置

- 业务数据：本机扩展的 IndexedDB（Dexie，库名 `seeklead-agent`），10 张表：产品/笔记/评论/分析/线索状态/纠正/任务/批次/用量/锁。不出本机、不云同步。
- API Key：`browser.storage.session`（会话）或 `browser.storage.local`（勾选记住）；永不写入 IndexedDB。
- 评论快照过期后按保留期清理；“已处理”标记永久保留，重新分析不会丢失。

## 卸载前导出

在“线索页”用“导出当前筛选 JSON/CSV”（或先把过滤设为全部）下载文件；JSON 含 `schemaVersion` 和画像版本，CSV 带 UTF-8 BOM 并做了公式注入防护。导出含打码后的业务字段与网友公开身份信息（昵称原文、小红书用户 ID、IP 属地、主页链接；昵称按 D006 保留原文），仅供你本地跟进使用——这些字段绝不会发送给 AI 模型。确认备份后再删除扩展；删除扩展会同时清空本机 IndexedDB。

## 已知限制（显眼提醒）

- **真实浏览器加载验收（T29）与真实模型效果评测（T30）未完成**：自动化测试全部基于 mock 与脱敏 fixture，不能据此宣称线上效果达标；高意向精确率 ≥85%、需求召回率 ≥80% 的目标尚无任何真实数据。
- 自动滚动仅在当前笔记内触发正常懒加载，不自动展开折叠回复或进入其他笔记；未新增停止、超时、500条上限均不能证明全部采集。验证码/登录限制、极慢加载或未知滚动容器可能阻止继续，详见 `docs/incremental-capture-2026-10-16.md`。
- 页面被验证码/登录遮挡时停止并提示，不尝试绕过。
- 产品页需要公开可访问；私网/带账号密码的 URL 会被直接拒绝。
- Edge 之外的浏览器、Windows 之外的系统未测试。

# 觅客Agent（SeekLead Agent）

觅客Agent 是一个获客插件，帮你从评论区里找客户。

贴上你的产品链接，它会先弄清你卖的是什么，生成一组搜索词，到你登录的小红书网页版里翻相关笔记和评论。评论先用 JEV 快速判别筛一遍，几秒内就能分出哪些人是真想买，再把问「哪里买」「求推荐」的人挑出来。每条线索都附上评论原文、意向分、判断理由和评论者主页，你点进去自己回复就行。

插件只读不写：不替你发私信，也不碰你的账号密码。第一版先支持小红书，抖音等平台后续接入。
